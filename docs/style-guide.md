# 스타일 가이드

## 기본 톤

- 한국어 존댓말을 일관되게 사용합니다.
- 친절하고 차분하게 설명합니다.
- 비전공자를 배려하되, 개념을 과하게 생략하지 않습니다.
- 독자가 지금 처음 듣는 말인지 항상 먼저 생각하고 씁니다.

## 절 구성 원칙

모든 `section-YY.md` 파일을 같은 틀에 기계적으로 맞추지 않습니다. 책처럼 자연스럽게 읽히는 것을 우선합니다.

- 절 제목이 질문이라면, 첫 2~3문단 안에서 먼저 답을 줍니다.
- 생소한 용어는 처음 등장하는 자리에서 바로 풀어서 설명합니다.
- 독자가 아직 모를 약어, 기술 이름, 서비스 이름은 설명 없이 튀어나오지 않게 합니다.
- `무엇인가`, `왜 중요한가`, `언제 쓰는가`, `특징은 무엇인가`, `무엇과 헷갈리는가`가 본문 흐름 안에서 드러나야 합니다.
- 필요한 만큼만 소제목을 씁니다. 소제목은 독자의 이해 순서를 돕는 용도여야 합니다.
- `핵심 정리`는 둘 수 있지만 모든 절에 억지로 붙이지 않습니다.
- `이해 체크`와 `더 읽기`는 부록, 장 말미, 워크북 버전에서 따로 강화할 수 있습니다.

## 서술 규칙

- "쉽게 말해", "한마디로" 같은 연결어는 남용하지 않습니다.
- 한 문단에는 가능한 한 하나의 핵심 메시지만 둡니다.
- 비유는 이해를 돕는 보조 수단으로만 씁니다. 정의를 대신하면 안 됩니다.
- "경험"이 필요할 때는 합성된 현장 사례를 사용합니다.
- 독자를 다그치는 표현을 피합니다.
- 내부 검증용 출처는 frontmatter에 보관하고, 독자용 본문에는 과하게 드러내지 않습니다.
- 설명하지 않은 용어를 질문이나 정리 문장에 먼저 쓰지 않습니다.

## 좋은 절의 조건

- 독자가 중간에 "그래서 이게 정확히 뭐지?"라는 질문을 덜 하게 만듭니다.
- 용어 설명과 쓰임새 설명이 함께 나옵니다.
- 현재 절 하나만 읽어도 최소한의 문맥이 복구됩니다.
- AI 시대와 연결하더라도 과장보다 판단 기준을 줍니다.
