# 편집 용어집

| 용어 | 기본 정의 | 편집 메모 |
| --- | --- | --- |
| 소프트웨어 | 컴퓨터가 해야 할 일을 표현한 논리와 절차의 묶음 | 프로그램보다 넓은 개념으로 사용 |
| 프론트엔드 | 사용자가 직접 보고 조작하는 화면과 상호작용 영역 | UI와 클라이언트 실행 환경 중심으로 설명 |
| 백엔드 | 데이터, 비즈니스 규칙, 외부 연동을 처리하는 서버 측 영역 | 단순히 "화면 뒤"라고 축약하지 않기 |
| API | 프로그램끼리 약속된 방식으로 기능과 데이터를 주고받는 접점 | 메뉴판 비유는 가능하지만 한계도 함께 설명 |
| 운영체제 | 하드웨어와 프로그램 실행을 관리하는 핵심 소프트웨어 | Windows, macOS, Linux 예시 활용 |
| 프로세스 | 실행 중인 프로그램 단위 | 프로그램과 구분해서 설명 |
| 스레드 | 프로세스 안에서 실행 흐름을 나눈 단위 | 동시성 설명과 함께 다루기 |
| 데이터베이스 | 데이터를 체계적으로 저장하고 조회하는 시스템 | 엑셀과 차이 강조 |
| 클라우드 | 인터넷을 통해 컴퓨팅 자원을 빌려 쓰는 방식 | "남의 컴퓨터"로만 끝내지 않기 |
| 컨테이너 | 애플리케이션 실행 환경을 패키징해 일관되게 실행하는 방식 | 가상머신과 비교 설명 필요 |
| 머신러닝 | 데이터에서 패턴을 학습해 예측이나 분류를 수행하는 방법 | AI 전체와 구분 |
| 인공지능 | 넓게는 지능적 작업을 수행하는 시스템 전반 | 머신러닝, 생성형 AI와 포함 관계 설명 |
