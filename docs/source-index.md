# 참고 자료 인덱스

이 문서는 에이전트와 편집자가 자주 참조해야 하는 기본 출처 지도입니다. 초고 단계에서는 빠르게 집필하되, `verified` 이상으로 올릴 때는 여기의 공식/권위 자료를 우선 사용합니다.

## 운영 원칙 참고

- OpenAI, "Harness engineering: leveraging Codex in an agent-first world" (2026-02-11)
  - https://openai.com/index/harness-engineering/
- AGENTS.md open format
  - https://agents.md/
- OpenAI Codex GitHub Action
  - https://github.com/openai/codex-action
- Quarto books
  - https://quarto.org/docs/books/
- Quarto CI / GitHub Actions
  - https://quarto.org/docs/publishing/ci.html
- Obsidian properties
  - https://help.obsidian.md/properties
- Obsidian callouts
  - https://help.obsidian.md/callouts

## 기술 검증 기본 방향

- 언어/프레임워크: 공식 문서 우선
- 웹 표준: WHATWG, MDN, IETF RFC 우선
- 운영체제/네트워크/DB 개념: 교과서적 정의 + 공식 벤더 문서 보강
- AI/클라우드: 공식 문서와 표준 용어집 우선

## 기록 방식

- 절 frontmatter의 `source_refs`에는 검증에 사용한 핵심 출처의 URL 또는 문서 ID를 넣습니다.
- 장 단위에서 중요한 공통 출처가 있으면 장 `index.md`에도 남깁니다.
