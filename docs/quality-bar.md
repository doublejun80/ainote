# 품질 기준

## 상태 정의

- `draft`: 구조는 갖췄지만 설명 밀도와 근거가 부족한 상태
- `reviewed`: 구조, 톤, 예시가 기준을 만족한 상태
- `verified`: 핵심 사실과 용어가 공식/권위 자료로 검증된 상태
- `final`: 장 단위 맥락, 링크, 중복, 흐름까지 확인된 상태

## 절 승격 기준

### `draft` -> `reviewed`

- 필수 10개 섹션이 모두 존재합니다.
- 생활 비유와 개발 현장 예시가 각각 최소 1개 있습니다.
- 초보자가 따라갈 수 있게 문단 길이와 설명 흐름이 정리되어 있습니다.

### `reviewed` -> `verified`

- `source_refs`가 비어 있지 않습니다.
- 핵심 정의와 비교 설명이 공식 또는 1차 자료와 충돌하지 않습니다.
- 오해하기 쉬운 표현이 정리되어 있습니다.

### `verified` -> `final`

- 같은 장의 다른 절과 톤과 난이도가 맞습니다.
- 내부 링크와 용어 연결이 정리되어 있습니다.
- 장 소개/장 정리 흐름 속에서 중복과 빈 구멍이 확인되었습니다.

## 장 품질 기준

- 장 서문이 질문 지형을 잡아 줍니다.
- 절 사이 연결이 자연스럽습니다.
- 장 말미에 "무엇을 이해했는지"를 스스로 확인할 수 있습니다.
