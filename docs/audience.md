# 독자 정의

## 핵심 독자

- 비전공자이지만 소프트웨어와 AI를 이해하고 싶은 성인 학습자
- 개발을 시작했으나 용어가 너무 많아 큰 그림을 놓친 초보자
- 현업 AI 도구를 쓰지만, 기반 개념이 약해 불안한 사람

## 독자의 현재 상태

- 용어를 들으면 어렴풋이 알지만, 서로 어떻게 연결되는지 모릅니다.
- "REST API", "클라우드", "스레드", "컨테이너" 같은 말을 자주 접하지만 자기 언어로 설명하기 어렵습니다.
- 강한 동기와 불안을 동시에 가지고 있습니다.

## 책이 제공해야 하는 가치

- 처음 읽을 때는 개괄적 지도 역할을 합니다.
- 다시 찾을 때는 빠르게 문맥을 복구할 수 있어야 합니다.
- 실무로 갈수록 더 깊게 공부할 다음 주제를 안내해야 합니다.

## 금지 사항

- 이미 아는 사람끼리만 통하는 압축된 설명
- 근거 없는 자신감이나 허세형 문장
- 실제 개인 경험처럼 꾸민 허구의 일화
