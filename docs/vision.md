# 비전

이 프로젝트의 목표는 AI 시대의 초보 개발자가 언제든 펼쳐 보고 전체 지형을 이해할 수 있는 한국어 지식서를 만드는 것입니다. 책은 단순한 정의 모음이 아니라, "왜 이것이 중요한가", "현실에서는 어떻게 쓰이는가", "AI 시대에는 무엇이 달라졌는가"를 한 번에 설명해야 합니다.

핵심 기준은 세 가지입니다.

1. 내용이 먼저입니다. 문장 톤이나 포맷보다, 개념을 정확하고 쉽게 연결하는 것이 우선입니다.
2. 초보자의 의욕을 꺾지 않아야 합니다. 설명은 친절해야 하지만, 내용을 얕게 만들지는 않습니다.
3. 에이전트가 계속 유지보수할 수 있어야 합니다. 규칙, 품질 기준, 참고 자료 경로가 저장소 안에 남아 있어야 합니다.

최종 산출물은 하나의 원고에서 파생됩니다.

- 저작 원본: Obsidian 호환 Markdown
- 출판 산출물: Quarto 기반 HTML, PDF, EPUB
- 운영 원칙: 짧은 진입 지침, 구조화된 문서 저장소, 작은 단위 집필/리뷰, 반복적 문서 가드닝
