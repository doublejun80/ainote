# 부록. 자주 묻는 질문

## 에이전트와 챗봇은 같은 건가요?

비슷하지만 완전히 같지는 않습니다. 챗봇이 대화 응답 중심이라면, 에이전트는 목표를 가지고 도구를 쓰며 여러 단계를 이어 갈 수 있는 흐름에 더 가깝습니다.

## 무조건 완전 자동화부터 목표로 해야 하나요?

대개는 아닙니다. 처음에는 사람 검토가 포함된 반자동 흐름이 훨씬 현실적이고 안정적입니다.

## 좋은 모델을 쓰면 설계 문제는 사라지나요?

아닙니다. 모델이 좋아져도 입력 구조, 검토 단계, 권한 제한, 평가 루프가 없으면 자동화는 쉽게 흔들립니다.
