# 2장. 프롬프트에서 워크플로우로 넘어가기

많은 사람이 AI 활용을 프롬프트 작성법에서 시작합니다. 출발점으로는 좋지만, 실제 업무 자동화는 프롬프트 한 줄보다 더 넓은 구조를 필요로 합니다. 입력과 출력 형식, 단계 분리, 검토 지점, 실패 처리 같은 요소가 함께 움직여야 하기 때문입니다.

이 장은 바로 그 전환점을 설명합니다. 잘 쓴 프롬프트가 왜 곧바로 좋은 워크플로우가 되지 않는지, 그리고 어떤 기준으로 단계를 나누면 자동화가 더 안정적으로 굴러가는지 살펴봅니다.
