# 2장. 화면과 사용자 상호작용

이 장에서는 사용자의 행동이 프론트엔드 안에서 어떻게 처리되는지 봅니다. 버튼 클릭, 폼 제출, 임시 저장, 반응형 레이아웃, 접근성 같은 주제들은 겉으로는 화면 문제처럼 보이지만, 실제로는 서비스 경험의 핵심을 결정하는 요소들입니다.

입문자는 자주 화면을 예쁘게 만드는 일과 사용자가 실제로 문제 없이 쓸 수 있게 만드는 일을 같은 것으로 착각합니다. 하지만 좋은 화면은 예쁜 화면이 아니라, 입력이 잘 되고, 상태가 적절히 남고, 기기와 조건이 달라도 큰 혼란 없이 동작하는 화면입니다. 이 장은 그 감각을 잡아 주는 데 목적이 있습니다.
