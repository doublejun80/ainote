# 부록. 점검표

1. 지금 문제는 화면 문제인가, 요청 문제인가, 서버 문제인가?
2. 브라우저 개발자 도구에서 에러와 네트워크를 확인했는가?
3. 입력 검증과 서버 검증을 둘 다 생각했는가?
4. 로컬과 배포 환경의 차이를 점검했는가?
5. 인증 정보와 비밀 값이 코드에 직접 들어가 있지 않은가?
6. 배포 뒤에 로그와 오류 확인 경로를 마련했는가?
