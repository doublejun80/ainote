# 부록. 핵심 용어집

- 브라우저: 사용자의 입력을 받고 웹 화면을 그려 주는 실행 환경
- 렌더링: HTML, CSS, 스크립트를 해석해 실제 화면으로 만드는 과정
- DOM: 브라우저가 HTML 문서를 구조화해 다루는 표현 방식
- API: 프론트엔드와 백엔드가 데이터를 주고받는 약속
- HTTP: 브라우저와 서버가 요청과 응답을 주고받을 때 널리 쓰는 규칙
- 인증: 사용자가 누구인지 확인하는 과정
- 인가: 확인된 사용자가 무엇을 할 수 있는지 판단하는 과정
- 쿠키: 브라우저에 저장되며 요청과 함께 서버로 전송될 수 있는 작은 데이터
- 환경변수: 코드 밖에서 주입해 환경별 설정을 분리하는 값
- 정적 배포: 미리 만들어진 파일을 그대로 제공하는 배포 방식
