# 부록

이 책의 부록은 본문을 다 읽은 뒤에만 보는 덧붙임이 아니라, 막힐 때 다시 방향을 잡기 위한 복귀 지점입니다. 용어가 흐려질 때는 용어집으로, 흐름이 섞일 때는 점검표로, 프로젝트 감각이 약할 때는 설계 노트로 돌아오면 됩니다.

웹 개발은 한 번에 모든 개념이 고정되기보다, 프로젝트를 하다가 다시 찾아보는 방식으로 익숙해지는 경우가 많습니다. 그래서 부록은 본문 요약본이 아니라, 다시 시작할 때 발판이 되는 자료 모음으로 구성했습니다.
