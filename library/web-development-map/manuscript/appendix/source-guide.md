# 부록. 참고 자료와 검증 원칙

웹 개발 기초를 확인할 때는 MDN과 web.dev 같은 공식 학습 자료를 먼저 보는 습관이 좋습니다. 브라우저 동작과 HTTP 의미처럼 규칙이 중요한 주제는 표준 문서와 권위 자료를 우선해 확인하는 편이 흔들림이 적습니다.

블로그와 영상은 이해를 돕는 보조 자료로 쓸 수 있지만, 개념 정의와 브라우저 동작, 보안 규칙은 공식 문서로 다시 확인하는 편이 좋습니다. 특히 로그인, 쿠키, CORS, HTTPS 같은 주제는 정확한 용어 구분이 중요하므로 2차 요약만 믿지 않는 습관이 필요합니다.
