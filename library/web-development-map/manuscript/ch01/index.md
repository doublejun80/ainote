# 1장. 브라우저와 첫 화면의 구조

웹 개발은 브라우저에서 시작합니다. 사용자는 브라우저를 통해 서비스를 만나고, 개발자는 HTML, CSS, JavaScript를 이용해 그 경험을 만듭니다. 하지만 이 셋을 따로따로 배우면 실제 서비스 감각이 잘 붙지 않습니다.

이 장에서는 먼저 브라우저가 어떤 일을 하는지, 주소를 입력하면 어떤 길로 페이지를 찾는지, 화면 기술 세 가지가 어떻게 역할을 나누는지, 그리고 받은 파일이 어떤 과정을 거쳐 실제 화면이 되는지를 함께 살펴봅니다. 이 장을 마치면 적어도 브라우저 안에서 무슨 일이 벌어지는지에 대한 기본 지도가 생겨야 합니다.
