# 10장. 클라우드, 빅데이터, 인공지능

개발 공부를 하다 보면 어느 순간 클라우드, 컨테이너, 쿠버네티스, 빅데이터, 머신러닝, 인공지능 같은 말이 한꺼번에 쏟아집니다. 이름은 화려한데 서로 어떤 관계인지 설명하기는 어렵고, 기술 뉴스만 따라가다 보면 더 혼란스러워집니다. 10장은 이 주제들을 유행어가 아니라 하나의 흐름으로 이해하기 위한 장입니다.

핵심은 간단합니다. 서비스가 커지고 데이터가 많아지고 자동화 수준이 높아지면서, 인프라를 더 유연하게 쓰는 방식이 필요해졌고, 많은 데이터를 다루는 기술이 중요해졌으며, 그 위에서 학습과 예측을 수행하는 인공지능 기술이 널리 쓰이게 되었습니다. 즉, 클라우드는 기반 인프라의 유연성, 빅데이터는 데이터 규모와 처리, 인공지능은 그 데이터 위에서의 학습과 판단이라고 볼 수 있습니다.

이 장에서는 각 용어를 따로 소개하되, 마지막에는 어떻게 이어지는지까지 정리합니다. 그래야 초보자도 각각의 기술을 독립된 섬이 아니라 현대 서비스 환경의 연결된 층으로 이해할 수 있습니다.
