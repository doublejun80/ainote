# 시스템 아키텍쳐란 무엇인가요?

시스템 아키텍처는 하나의 서비스나 시스템이 어떤 부품으로 나뉘고, 그 부품들이 어떻게 연결되고, 어떤 규칙을 따르며 움직이는지를 정한 큰 구조입니다. 기능 목록을 나열하는 것이 아니라, 그 기능들이 어떤 틀 안에서 협력할지를 설계하는 일이라고 보면 됩니다. 그래서 아키텍처는 코드 몇 줄보다 경계와 흐름에 더 가깝습니다.

예를 들어 쇼핑몰 시스템을 만든다고 할 때, 사용자 화면, 주문 처리, 결제 연동, 재고 관리, 알림 발송, 관리자 기능을 모두 하나의 덩어리로 만들 수도 있고 여러 부분으로 나눌 수도 있습니다. 어디까지를 한 묶음으로 보고, 어디서부터 분리할지 결정하는 것이 아키텍처의 핵심 질문입니다.

## 아키텍처는 무엇을 포함하나요

첫째, 구성 요소가 무엇인지가 들어갑니다. 화면 계층, 애플리케이션 계층, 데이터 저장 계층, 외부 연동 계층 같은 큰 블록이 여기에 속합니다. 둘째, 이들이 어떤 방식으로 통신하는지 정합니다. 동기 호출인지, 메시지 기반인지, API 계약은 어떻게 관리할지 같은 문제입니다.

셋째, 품질 속성에 대한 선택이 들어갑니다. 빠른 응답이 중요한지, 변경이 쉬운 구조가 중요한지, 장애가 일부에만 머무르게 하는 것이 중요한지에 따라 아키텍처가 달라집니다. 즉, 아키텍처는 기능 구현 전의 추상 이론이 아니라 품질 우선순위를 반영한 구조 결정입니다.

## 초보자는 왜 아키텍처를 어렵게 느낄까요

아키텍처는 눈앞의 화면 동작보다 한 단계 위에서 생각해야 하기 때문입니다. 버튼이 눌리는 코드보다, 그 버튼이 일으키는 요청이 어느 계층을 지나고 어떤 서비스와 데이터에 영향을 주는지를 봐야 합니다. 하지만 그렇다고 아주 거대한 시스템을 다뤄야만 아키텍처를 배우는 것은 아닙니다. 작은 프로젝트에서도 폴더 구조, 책임 분리, 데이터 흐름 설계는 이미 아키텍처의 시작입니다.

초보자는 먼저 "역할을 어디서 나눌까"라는 질문부터 시작하면 좋습니다. 화면이 데이터를 직접 만지지 않게 할지, 인증을 공통 계층으로 뺄지, 외부 API 연동 코드를 다른 코드와 분리할지 같은 선택이 바로 아키텍처 감각을 키웁니다.

## 핵심만 다시 정리하면

시스템 아키텍처는 시스템을 어떤 구성 요소로 나누고, 어떻게 연결하고, 어떤 품질 목표를 우선할지 정하는 큰 구조입니다. 이는 기능 목록이 아니라 구조와 경계와 흐름에 대한 설계입니다. 초보자도 작은 프로젝트에서 역할 분리와 데이터 흐름을 의식하는 것부터 아키텍처를 배울 수 있습니다.

## 이 내용을 알면 어디서 덜 막히는가

이 개념을 이해하면 시스템 경계, 책임 분리, 확장성, 장애 전파 제어와 관련된 질문을 훨씬 현실적으로 바라볼 수 있습니다. 실제로는 기능을 어디까지 나누고 어디서 묶을지 결정할 때 이 개념이 다시 등장합니다.

그래서 이 절의 설명은 곧 아키텍처가 거창한 그림이 아니라 현실 비용을 줄이는 설계임을 이해하게 됩니다

## 읽다가 흔들리는 지점

이 주제에서 가장 흔한 오해는 아키텍처를 전문가 전용 설계도처럼 보거나, 서비스를 잘게 나누기만 하면 자동으로 좋아진다고 믿는 점입니다.

중요한 것은 이름보다 경계와 책임, 통신 비용, 장애 전파 방식이라는 사실을 먼저 잡는 편이 좋습니다. 이 기준만 있어도 뒤 장에서 같은 말을 다시 만나도 훨씬 덜 흔들립니다.

## 손으로 확인해 보면 더 빨리 남습니다

이 개념은 읽는 것만으로는 쉽게 손에 잡히지 않습니다. 아주 작은 확인만 해도 본문이 훨씬 입체적으로 보입니다.

1. 익숙한 서비스 하나를 상자로 나누어 그려 보고 이 개념이 어느 경계에서 중요한지 표시해 봅니다.

2. 요구사항이 하나 바뀌었을 때 어떤 부분이 함께 흔들릴지 상상해 보면 구조 감각이 생깁니다.

3. 장애가 났을 때 어디까지 번질지, 어느 지점에서 막을 수 있을지 말로 설명해 봅니다.

## 책 전체 흐름 속에서의 자리

이 개념은 여기서 끝나는 개념이 아닙니다. 이 절에서 잡은 감각은 5장의 협업 방식, 8장의 네트워크, 10장의 클라우드 운영로 이어집니다.

따라서 다음 절을 읽을 때는 "이 개념이 지금 설명하는 층은 어디인가"를 계속 추적해 보세요. 그 습관이 전체 책을 훨씬 쉽게 만듭니다.
