# Source Research

Use this skill to collect source candidates for a manuscript section without bloating the draft.

## Workflow

1. Read the target section title and chapter index first.
2. Read [../../docs/source-index.md](../../docs/source-index.md) to choose the right source class.
3. Prefer official docs, standards, or primary vendor references.
4. Capture only the few sources that materially improve accuracy.
5. Add sources to frontmatter `source_refs` and summarize the reason each source matters in working notes or PR text.

## Output Rules

- Do not dump long quotes into the manuscript.
- Do not add sources just to increase count.
- If a concept is unstable or vendor-specific, prefer the latest official doc.
- If a concept is stable and foundational, use textbook-level definitions plus an official reference when possible.

## Checklist

- Is the source authoritative?
- Is the source recent enough for the claim?
- Does it help a beginner avoid a likely misunderstanding?
- Does it belong in `source_refs`, not the prose body?
