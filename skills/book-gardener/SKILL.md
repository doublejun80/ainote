# Book Gardener

Use this skill for small, safe maintenance tasks.

## Workflow

1. Run deterministic checks first.
2. Fix mechanical issues before touching prose.
3. Prefer narrow changes that keep the repo legible.
4. Leave substantive teaching decisions to a focused drafting task.

## Safe Changes

- Sync generated outline files
- Fix metadata drift
- Repair broken manuscript links
- Normalize repeated placeholders
- Update workflow or docs references when paths change

## Avoid

- Rewriting many sections for style in one pass
- Inventing new scope or chapter structure without direction
- Promoting sections to `final` without verification evidence
